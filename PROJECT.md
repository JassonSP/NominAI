# Proyecto NominAI

## Objetivo

Desarrollar una plataforma capaz de estimar el valor de la nómina de un trabajador colombiano utilizando únicamente la información de su horario laboral y las reglas de liquidación definidas para cada empresa.

## MVP

Versión 1.0

Empresa soportada:

- Atlantic Quantum Innovations

El sistema deberá permitir:

- Registrar el horario trabajado.
- Identificar automáticamente horas normales.
- Identificar horas nocturnas.
- Identificar horas festivas.
- Identificar horas dominicales.
- Calcular salario básico.
- Calcular recargos.
- Calcular descuentos.
- Mostrar el valor neto estimado.

## Objetivos futuros

- Historial de nóminas.
- Múltiples empresas.
- Aplicación móvil.
- IA para leer desprendibles.
- Motor configurable por empresa.
