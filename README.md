# NominAI

NominAI es una aplicación web diseñada para estimar el valor de la nómina de un trabajador colombiano a partir de su horario laboral.

El objetivo es permitir que los usuarios conozcan cuánto recibirán en su próxima quincena antes de que la empresa genere el desprendible de pago.

La aplicación analiza automáticamente el horario ingresado por el usuario y calcula el salario teniendo en cuenta las reglas de liquidación de cada empresa.

## Características

- Registro de horarios por día.
- Cálculo automático de horas trabajadas.
- Cálculo de horas nocturnas.
- Cálculo de horas festivas.
- Cálculo de trabajo dominical.
- Cálculo de recargos.
- Estimación de salario.
- Variables y comisiones.
- Auxilios y beneficios.
- Descuentos legales.
- Simulación del desprendible de nómina.

## Estado del proyecto

En desarrollo.

La primera versión soportará exclusivamente la empresa **Atlantic Quantum Innovations**, con el objetivo de validar el motor de cálculo antes de incorporar nuevas empresas.
